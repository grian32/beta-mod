The **Enhancement Table** is a station used to apply and upgrade [item enhancements]({{< relref "/mechanics/item-enhancements.md" >}}).

### Crafting

{{< recipe id="enhancement_table" >}}

## Usage

Place a tool and the required enhancement ingredient into the Enhancement Table to apply an enhancement. Higher enhancement tiers must be applied by upgrading the existing enhancement.
