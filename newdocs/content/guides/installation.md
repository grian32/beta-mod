Project Beta Expanded is a mod for Minecraft Beta 1.7.3 that reimagines the game as the foundation for an alternate path of development. It fixes vanilla annoyances, completes unfinished features, and introduces new content guided by its own design philosophy.

The mod is intended to be played standalone. It may work alongside other mods, but compatibility issues may occur.

## Installing

1. Install the [Babric Prism Instance](https://github.com/babric/prism-instance).
2. Add [Glass Config API](https://modrinth.com/mod/glass-config-api), [Fabric Language Kotlin 1.10.18+kotlin1.9.22](https://modrinth.com/mod/fabric-language-kotlin/version/1.10.18+kotlin.1.9.22), [StationAPI](https://modrinth.com/mod/stationapi), and [Mod Menu Beta](https://modrinth.com/mod/modmenu-beta) to the instance's `mods` folder.
3. Add the Project Beta Expanded jar to the `mods` folder.

## Compatibility

There are currently no known conflicts with other mods.

## Configuration

The mod's features are heavily interconnected, so most cannot be configured independently. The version string modification can be disabled.
