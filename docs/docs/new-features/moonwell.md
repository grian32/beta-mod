# Moonwell

The Moonwell is a new station that passively harvests the power of the moon to repair enhanced items at night.

![Moonwell](/img/moonwell.png)

It takes about two nights to repair a diamond tool from nearly broken to full durability, while lesser tiers will take less time.

Right-click the Moonwell with an enhanced item to insert it, then right-click it with an empty hand to retrieve it.

The moonwell will work twice as fast under a broken moon.
